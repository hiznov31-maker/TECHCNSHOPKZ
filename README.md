# Китайские флагманы: запуск

## 1. Открыть сайт для всех (ошибка 401)
Netlify → Site configuration → Access & security → отключите *Password protection* / *Visitor access control*. Пока это включено, покупатели видят 401.

## 2. Свой домен
Netlify → Domain management → Add a domain. После этого замените в `index.html` адрес картинки превью на полный:
`sed -i 's#content="og.png"#content="https://ВАШ-ДОМЕН/og.png"#g' index.html`
(Telegram показывает превью ссылки только с полным адресом картинки.)

## 3. Заявки в Telegram-бот
1. В Telegram откройте @BotFather → /newbot → получите токен.
2. Напишите своему боту любое сообщение, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`. Это TG_CHAT_ID.
3. Netlify → Site configuration → Environment variables: добавьте `TG_BOT_TOKEN` и `TG_CHAT_ID`.
4. Функция `netlify/functions/order.js` работает только при деплое из GitHub (или через Netlify CLI), перетаскивание папки в окно Netlify функции не публикует.
Если бот не настроен, форма покажет ошибку и предложит кнопку «Открыть Telegram»: заказ по-прежнему можно отправить сообщением.

## 4. GitHub
Создайте репозиторий, положите туда все файлы из этой папки, затем Netlify → Add new site → Import from Git.

## 5. Аналитика
Самый простой вариант: счётчик GoatCounter (бесплатно). Добавьте перед `</head>` строку из личного кабинета, события сайта (`checkout_open`, `order_submit`, `order_telegram`, `order_form_error`) отправятся автоматически. Для Яндекс.Метрики задайте `window.YM_ID = 12345678;` до подключения счётчика.

## 6. Калькулятор закупки
Откройте сайт с `#admin` в конце адреса: сверху курс, наценка и доставка, под ними калькулятор (юани → цена, прибыль, сравнение с OLX).
Внимание: закупочные цены лежат в коде страницы, их видно в «просмотре кода». Если это нежелательно, нужна сборка публичной версии без закупки.
